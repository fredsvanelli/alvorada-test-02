Added a `checks` job to CI that runs `npm test -w web`, `npm run lint`, `npm run typecheck` and `npm run build`, and moved the shared Node and `npm ci` steps into `.github/actions/setup`. The failure path was not exercised, so a failing command failing the checks rests on GitHub's default behavior. `main` has no branch protection, so a red check does not block a merge.
