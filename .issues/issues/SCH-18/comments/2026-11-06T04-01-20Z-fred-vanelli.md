## Plan

Decided in a grill session: active bars stay drawn over canceled ones (old AC2 dropped), hover expands a bar, keyboard focus does not.

1. **Ellipsis** (`web/src/components/bookings/timeline.tsx`): wrap the label in `<span className="truncate">` and drop `text-ellipsis whitespace-nowrap` from the bar. `text-overflow` does not apply to a flex container, which is why `B [90,100)` was cut with no sign. The `title` and label text stay, so the full label stays in the page and the tooltip. A bar narrower than its padding shows no text.
2. **Hover expansion**: `timelineRows` (`web/src/lib/bookings.ts`) gives each bar `growsLeft: booking.start > max / 2`. Such a bar is positioned with `right` instead of `left`, so it widens to the left. Every bar gets `hover:min-w-max hover:z-10`, CSS only, with no focus styles.
3. **Unit test** (`web/src/lib/bookings.test.ts`): `growsLeft` is true at start 90, false at 10 and false at exactly 50 on a 0 to 100 axis.
